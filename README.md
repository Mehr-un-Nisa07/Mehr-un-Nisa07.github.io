# Personal Portfolio Website

A multi-page personal portfolio website showcasing my projects, skills, and experience as a junior web developer.

## 🔗 Live Demo
[Visit Live Site](https://mehr-un-nisa07.github.io/)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- GitHub Pages (Hosting)

## ✨ Features
- Multi-page layout (Home, About, Projects, Contact)
- Fully responsive design — works on desktop, tablet and mobile
- Smooth scroll animations on page elements
- Filterable projects section (All / Live Sites / Client Work / PHP-MySQL / HTML-CSS-JS)
- Working contact section with WhatsApp, Gmail, and copy-email buttons
- Clean, modern dark theme with accent highlights

## 📄 Pages
- **Home** — Introduction, quick stats, featured projects
- **About** — Detailed background, skills breakdown, education timeline
- **Projects** — Full list of all projects with live links and filtering
- **Contact** — Multiple ways to get in touch
